## 📱 About This Project

Weather App is a simple mobile application built with **Flutter and Dart** to display weather information using the **Open-Meteo API**.

This project demonstrates how to fetch data from an API, process JSON responses, and display dynamic information in a mobile application.

## ✨ Features

- 🌡️ Display current temperature
- 🌤️ Show weather conditions
- 💧 Display humidity
- 💨 Show wind speed
- 🕒 Display weather observation time
- 🔄 Refresh weather data
- ⏳ Loading indicator
- ⚠️ Error handling

## 🛠️ Built With

- Flutter
- Dart
- Open-Meteo API
- HTTP package
- Android Studio
